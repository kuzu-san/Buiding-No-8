# 🏢 Building No.8

---

## 📖 О игре

**Building No.8** — трёхмерная игра в жанре симулятора управления зданием студенческого общежития с элементами стратегии и тайм-менеджмента, вдохновлённая серией Five Nights at Freddy's.

Ты — заведующий студенческим общежитием. Твоя смена длится с **09:00 до 18:00**. На каждом этаже постоянно что-то происходит: студенты недовольны, возникают инциденты, обстановка накаляется. Следи за камерами, звони работникам и не давай ситуации выйти из-под контроля.

---

## 🎮 Геймплей

Вся игра проходит в **комнате заведующего**. Отсюда ты управляешь зданием с помощью нескольких инструментов.

### Инструменты

**📹 Система видеонаблюдения**
Переключайся между камерами на каждом этаже. Следи за обстановкой — камеры покажут где возникли инциденты.

**📞 Телефон**
Набери номер нужного работника на физическом аппарате, выбери этаж — и он устранит проблему. После вызова работник недоступен некоторое время (кулдаун).

**💡 Панель индикации**
Физическое устройство на стене показывает состояние каждого этажа в реальном времени:
- **Левый столбец** — лампочки этажей. Жёлтая = этаж просматривается на камере
- **Строки лампочек** — уровень напряжённости на этаже (5 ступеней):

| Лампочка | Цвет | Уровень |
|---|---|---|
| 1 | 🟢 Светло-зелёная | 20% |
| 2 | 🟩 Зелёная | 40% |
| 3 | 🟡 Жёлтая | 60% |
| 4 | 🟠 Оранжевая | 80% |
| 5 | 🔴 Красная | 100% — критическое состояние |

**🕐 Электронные часы**
Показывают текущее игровое время.

**📋 Листок с номерами**
Нажми на листок — он приблизится к экрану. Смотри номера работников и набирай их на телефоне.

## ⌨️ Управление

| Действие | Клавиша / кнопка |
|---|---|
| Переключение точки обзора | `A` / `D` |
| Пауза | `Escape` |
| Набор номера на телефоне | Физические кнопки 0–9 на сцене |
| Вызов / Сброс | Зелёная / Красная кнопки на телефоне |
| Взаимодействие с объектами | Левая кнопка мыши |
